# RIGOL 仪器控制面板

通过 USB 连接 RIGOL DM3068（数字万用表）和 DG1062（信号发生器），实时监测 AC 电流，欠流时自动保护关断输出，并记录数据 + 实时绘制电流-时间曲线。

## 功能

| 功能 | 说明 |
|------|------|
| **设备连接** | 自动扫描 USB TMC 仪器，支持 RIGOL / Tektronix / Keysight / Siglent 等多厂商 |
| **电流监测** | 实时读取 DM3068 AC 电流，大字体显示，mA / µA 自动切换 |
| **欠流保护** | 电流连续 2 次低于阈值 → 自动关断 DG1062 输出，监测继续运行 |
| **输出控制** | 手动开关 DG1062 信号源，实时查询输出状态 |
| **数据记录** | 随输出自动启停，TSV 格式，时间从 0 开始（相对秒数） |
| **实时曲线** | 内嵌 matplotlib 图表，电流-时间实时绘制，阈值参考线 |
| **消息日志** | 底部日志面板，带颜色标签 |

## 依赖

- Python 3.13+
- pyvisa + pyvisa-py（USBTMC 通信）
- matplotlib（实时曲线）
- tkinter（GUI，Python 自带）

## 安装

```bash
pip install -r requirements.txt
```

确保设备通过 USB 连接，Windows 设备管理器中应出现 **USB Test and Measurement Devices**。

## 使用

```bash
python rigol_control.py
```

或双击 `run.bat`。

### 典型工作流程

1. 点击 **↻ 刷新设备列表** 检测 USB 仪器
2. 分别选择 DM3068 和 DG1062，点击 **连接**
3. 两个设备都连接后自动开始电流监测
4. 设置 **电流阈值** 和 **记录间隔**
5. 点击 **● 开启输出** → 同时开始数据记录 + 实时绘图
6. 点击 **○ 关闭输出**（或保护自动触发）→ 自动停止记录
7. 数据文件保存在程序目录，可用 Excel / Python 等打开分析

### 数据文件格式

```tsv
# RIGOL DM3068 电流数据记录
# 开始时间: 2026-07-14 15:30:00
# 格式: 相对时间(s)	电流(mA)
0.250	1.234567
0.500	1.245678
0.750	1.239012
...
# 结束时间: 2026-07-14 15:32:00
# 总时长: 120.500 s
# 共记录: 482 条
```

第一列是相对秒数（从 0 开始），第二列是电流值（mA）。
